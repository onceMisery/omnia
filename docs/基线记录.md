## 3. 源码引用约定

- 引用须包含仓库名、仓库相对唯一路径、冻结 commit（可引用本表）及符号/行号；行号以冻结版本为准。原版文档仅作线索，冲突由冻结源码裁定。
- 读取基线使用 `git -C <仓库绝对路径> show <冻结commit>:<文件>`，不需要切换分支、stash 或改变原仓库。
- 目录存在性可用 `git ls-tree` 核验；工作区文件存在不能代替“冻结版本包含此文件”。
- 旧 `workspace/VCP复刻/reference/` 路径只属于历史记录，不用于新引用。
- 【已验证】仅描述上游证据；【已冻结】描述条目成熟度；实现状态另记（README §5）。

## 4. 上游跟进流程

1. 本项目不自动追随上游。里程碑启动时比较冻结 commit 与候选 commit，记录变化范围和理由。
2. 涉及协议、数据、插件、记忆或 UI 行为的变更逐项核对，重录受影响 fixture；不能只抽检行号或只看 diff 统计。
3. 换基线须更新本记录、README 项目基线、架构 §3、范围矩阵盘点、相关 PRD/契约与引用，保留旧新 commit 和决策记录。
4. vendoring 同步记录本地补丁、许可、构建与回归证据。锁定依赖升级另按使用与维护 §6，不与换 VCP 基线混为一项。
5. 禁止在实现中途静默换基线；文档检查通过不能代替行为对拍。
